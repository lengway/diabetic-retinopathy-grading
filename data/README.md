# Данные

Снимки в репозиторий не коммитятся. Скачайте датасеты локально в эту папку.

| Датасет | Назначение | Объём | Источник |
|---------|-----------|-------|----------|
| APTOS 2019 Blindness Detection | обучение / валидация | 3 662 размеченных снимка | Kaggle (нужен аккаунт и принятие правил соревнования) |
| EyePACS (Kaggle DR Detection 2015) | обучение / валидация | ~35 тыс. train | Kaggle |
| IDRiD | внешняя проверка | 516 снимков (градация) | IEEE DataPort |
| Messidor-2 | внешняя проверка | 1 748 снимков | ADCIS (по запросу) |

Условия использования каждого датасета проверяются и фиксируются в `docs/` до начала обучения.

Ожидаемая структура:

```
data/
  aptos2019/
  eyepacs/
  idrid/
  messidor2/
```
