# DR Grading Assistant

**Разработка интеллектуального ассистента для градации диабетической ретинопатии по снимкам глазного дна**

Дипломный проект, Astana IT University, Software Engineering.

> Исследовательский прототип. Не является медицинским изделием и не предназначен для постановки диагноза.

## Проблема

По данным IDF Diabetes Atlas (11-е изд., 2025), в 2024 году диабет был у ~589 млн взрослых 20–79 лет, а к 2050 году прогнозируется ~853 млн; 43% не знают о своём диагнозе. Диабетическая ретинопатия (ДР) развивается примерно у 22% людей с диабетом (Teo et al., *Ophthalmology*, 2021) и на ранних стадиях протекает бессимптомно. Скрининг по снимкам глазного дна требует времени офтальмолога, которых не хватает, особенно вне крупных городов.

## Пользователи

- врач-офтальмолог / врач общей практики, проводящий скрининг;
- оператор фундус-камеры в клинике или скрининговом пункте.

## Планируемый сценарий системы

1. Принимает снимок глазного дна.
2. Определяет стадию ДР по шкале ICDR (0 — нет, 1 — лёгкая, 2 — умеренная, 3 — тяжёлая непролиферативная, 4 — пролиферативная).
3. Вычисляет исследовательский флаг DR ≥ 2: score = p2+p3+p4, флаг по порогу, выбранному на calibration. Это не полное клиническое решение о направлении.
4. Планируется показывать уверенность с оценкой калибровки и карту Grad-CAM для анализа ответа. Перечисленные функции пока проектируются.

## Ожидаемые результаты

- модель градации ДР, обученная на открытых датасетах (APTOS 2019, EyePACS) и проверенная на внешних (IDRiD, Messidor-2);
- отчёт о кросс-датасетной обобщаемости и калибровке;
- веб-сервис: загрузка снимка → стадия, уверенность, тепловая карта, рекомендация;
- документация: требования, архитектура, план верификации.

## Scope и статус

**В scope:** градация ДР (5 классов) и бинарное решение referable DR; кросс-датасетная проверка; калибровка; Grad-CAM; веб-сервис.
**Вне scope:** сегментация поражений, другие патологии (глаукома, ВМД), мобильное приложение, доменная адаптация.

**Статус:** этап анализа и проектирования (октябрь 2026). Подробнее — [docs/proposal.md](docs/proposal.md).

## Технологии (план)

Python, PyTorch (+ timm), ONNX Runtime, FastAPI, Docker, pytest. Окончательный выбор фиксируется в [docs/adr/](docs/adr/).

## Структура репозитория

```
src/dr_assistant/   исходный код (данные, модели, обучение, сервис)
tests/              тесты
notebooks/          разведочный анализ и эксперименты
configs/            примеры конфигураций (без секретов)
docs/               proposal, обзор литературы, сравнения, требования, ADR, встречи
diagrams/src/       исходники диаграмм (PlantUML / Mermaid)
diagrams/export/    экспорт диаграмм (PNG / SVG)
data/               локальные данные (в git не попадают, см. data/README.md)
```
