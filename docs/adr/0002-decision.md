# ADR-0002: Baseline architecture

Дата: 20.10.2026. Статус: предложено, ожидает проверки реализацией. DIP-5.

## Решение

EfficientNet-B0; ResNet50 для сравнения.

## Причина

компактный baseline при ограниченных ресурсах. Альтернативы и первичные источники: ../technology-comparison.md.

## Последствия

сравнивать при одинаковом split; не обещать превосходство до измерений. Пересмотр при отрицательном пробном запуске или ограничении бюджета. Решение не представляется согласованным руководителем.
