# ADR-0001: ML framework

Дата: 20.10.2026. Статус: предложено, ожидает проверки реализацией. DIP-5.

## Решение

PyTorch.

## Причина

доступен MPS и градиенты для анализа CNN. Альтернативы и первичные источники: ../technology-comparison.md.

## Последствия

проверить операции MPS и закрепить зависимости после первого запуска. Пересмотр при отрицательном пробном запуске или ограничении бюджета. Решение не представляется согласованным руководителем.
