# Статус загрузки формы

20.10.2026: студент разрешил загрузить два подготовленных PDF без отправки ответа.

В Chrome заполнены поля 1–7: тема, руководитель, участник, репозиторий, планируемая ссылка на тег, вклад и ограничения. Форма находится на странице 3 из 5, поле 8.

Попытка загрузить PDF YouTrack остановлена расширением до передачи файла: требуется разрешение ChatGPT extension «Allow access to file URLs». Файлы в форму не загружены, ответ не отправлен. Настройки расширения не изменялись. После включения пользователем доступа можно повторить разрешённую загрузку и проверить страницы 4–5; финальная отправка не разрешена.

Тег prob-period-1 пока не создан; поле 5 содержит планируемую ссылку. До финальной подачи определить окончательную версию, создать тег и проверить доступность ссылки. Доступ руководителя и комиссии по-прежнему требует проверки.
