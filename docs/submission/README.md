## До финальной отправки

- Провести и зафиксировать 3–5 бесед с пользователями либо подтвердить допустимость другого свидетельства реального клиента. Литература это требование не заменяет.
- Получить фактическую обратную связь руководителя на пакет; нового отзыва нет.
- Проверить условия наборов, получить данные и выполнить EDA по DIP-6, обещанный в задании первой недели. В этой версии только план данных.
- Уточнить полный официальный список разделов, если школа выдала отдельный регламент.
- Дать комиссии чтение репозитория и YouTrack. Известных аккаунтов комиссии нет; внешний доступ не проверен. Не менять частный репозиторий на публичный без решения владельца.
- Сверить вклад и актуальные статусы задач, обновить PDF после фактических изменений.
- Войти университетским аккаунтом в Microsoft Forms, сверить обязательные поля и лимиты файлов, загрузить два PDF и сохранить подтверждение отправки. В этой сессии форма не отправлена.

Это перечень открытых условий сдачи, а не подтверждение полной готовности пакета. История коммитов сохраняется с настоящими датами; прежние просроченные задачи не маскируются переносом сроков.

Форма содержит пять страниц. Она явно принимает GitLab/GitHub. Поле 5 требует прямую ссылку на тег `prob-period-1`; тег должен указывать на ту же версию, что и загружаемые PDF. Поле 8 принимает один PDF скриншотов до 10 MB; для завершённой задачи нужны результат, критерии и ссылка на коммит/PR. Скриншоты включают DIP-1 с такой ссылкой.
