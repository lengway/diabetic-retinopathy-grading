# 4. Сравнение существующих систем

DIP-4. 20.10.2026. Три системы сравниваются по восьми критериям. Источники — конкретные документы FDA, а не обещание актуальности всех версий продуктов. Приведённые характеристики относятся только к указанным регистрационным версиям.

| Критерий | IDx-DR [S1] | EyeArt [S2] | AEYE-DS [S3] |
|---|---|---|---|
| Основание сравнения | De Novo DEN180001, 2018 | 510(k) K200667, 2020 | 510(k) K240058, 2024 |
| Назначение | автоматическое выявление more-than-mild DR | выявление mtmDR и vision-threatening DR | автоматическое выявление mtmDR |
| Целевая группа | взрослые с диабетом без ранее диагностированной ДР | взрослые с диабетом, ограничения определены IFU | взрослые с диабетом без ранее диагностированной ДР |
| Уровень вывода | скрининговый результат mtmDR | скрининговые конечные точки | скрининговый результат mtmDR |
| Пять стадий ICDR как пользовательский ответ | не заявлены в рассмотренном назначении | не заявлены в рассмотренном назначении | не заявлены в рассмотренном назначении |
| Оборудование | Topcon NW400 | совместимость ограничена камерами, указанными в документе | Topcon NW400 и Optomed Aurora |
| Пригодность снимка | предусмотрен контроль качества изображения | предусмотрен контроль качества изображения | предусмотрен контроль качества изображения |
| Проверка перед выводом на рынок | клинические материалы в De Novo | материалы клинической проверки и эквивалентности в 510(k) | материалы клинической проверки и эквивалентности в 510(k) |

Для критерия «пять стадий» отсутствие утверждения в документе не означает доказанного отсутствия функции во всех версиях продукта. Открытые веса, цены, доступность в Казахстане и пользовательская калиброванная вероятность по рассмотренным материалам не установлены; эти свойства не получают вымышленных оценок.

## Выводы для проектирования

Общее ограничение сравниваемых решений — определённое назначение, популяция и совместимое оборудование. Следовательно, учебный прототип с произвольной загрузкой снимка не может наследовать их клинические выводы. Контроль декодирования файла также не равнозначен клинической оценке пригодности изображения.

Разрабатываемый проект ориентирован на исследовательскую воспроизводимость: пять классов, отдельная бинарная метка DR >= 2, внешняя проверка, калибровка и анализ Grad-CAM. Это проектируемые свойства, а не достигнутые преимущества. В отличие от определения mtmDR в регистрационных документах, бинарная метка проекта не включает отдельное выявление DME. Числа sensitivity/specificity разных испытаний намеренно не ранжируются: популяции, эталоны и конечные точки различаются.
